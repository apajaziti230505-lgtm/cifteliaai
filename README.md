# Çiftelia Studio AI

Aplikacion lokal në Python për analizimin e audios dhe videos së çiftelisë, redaktimin e tablaturës dhe ruajtjen në JSON.

## Funksionet
- Import MP4 dhe audio
- Identifikim orientues i notave dhe goditjeve
- Shtim, ndryshim, fshirje dhe zhvendosje të notave
- Luajtje në 1.00×, 0.50× dhe 0.25×
- Eksport dhe import JSON

## Instalimi në Windows
1. Instalo Python 3.10+.
2. Shkarko dhe çpaketo skedarët e aplikacionit.
3. Ekzekuto `Start_Windows.bat`.

Lexo [udhëzuesin në shqip](UDHEZUES_SHQIP.md).
